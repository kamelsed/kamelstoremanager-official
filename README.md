# 🟦 Kamel Store Manager – Gestion Professionnelle

Bienvenue sur le site officiel de **Kamel Store Manager**, une application complète de gestion de magasin.

## 🌍 À propos
Kamel Store Manager est un logiciel professionnel développé par **Kamel Rabehi**, conçu pour :
- Gérer les ventes, les factures, les bons de commande et de livraison  
- Suivre les stocks et les alertes de rupture  
- Administrer les clients et fournisseurs  
- Imprimer les documents (factures, tickets thermiques, bons, etc.)
- Calculer la TVA automatiquement  
- Gérer les utilisateurs avec authentification sécurisée (bcrypt)

## 💼 Plateformes
Disponible pour :
- **Windows (.exe)**  
- **Linux (.AppImage)**

## 🧾 Fonctionnalités principales
- Interface PyQt6 moderne et sombre  
- Impression WYSIWYG et aperçu avant impression  
- Gestion complète des produits (CRUD)  
- Export Excel et affichage dans table DBGrid  
- Authentification sécurisée avec récupération de mot de passe  
- Support de paiement en ligne via **PayPal** et **RedotPay**
